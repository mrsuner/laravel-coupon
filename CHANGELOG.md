# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-30

### Added

- Initial stable release for Laravel 12 and 13.
- Coupon generation, validation, redemption recording, immutable redemption snapshots, lifecycle administration, and the `CouponRedeemed` integration event.
- Standalone Sanctum administration routes and automatic integration with `mrsuner/laravel-api-boilerplate`.
